# Advanced Python Concepts

## 1. Decorators

Decorators are a powerful feature in Python that allow developers to modify or extend the behavior of functions and classes without changing their source code. A decorator is essentially a function that takes another function as an argument and returns a new function.

Example:

```python
def logger(func):
    def wrapper(*args, **kwargs):
        print(f"Calling {func.__name__}")
        return func(*args, **kwargs)
    return wrapper

@logger
def greet():
    print("Hello")

greet()
```

Decorators are commonly used for logging, authentication, caching, rate limiting, and performance monitoring.

## 2. Generators

Generators provide a memory-efficient way to iterate over large datasets. Instead of storing all values in memory, generators yield values one at a time.

Example:

```python
def count_up_to(n):
    count = 1
    while count <= n:
        yield count
        count += 1

for num in count_up_to(5):
    print(num)
```

Benefits:

* Reduced memory consumption
* Lazy evaluation
* Suitable for processing large files and streams

---

## 3. Iterators and Iterable Objects

An iterable is an object capable of returning its members one at a time. An iterator implements the `__iter__()` and `__next__()` methods.

Example:

```python
class Counter:
    def __init__(self, max_count):
        self.max_count = max_count
        self.current = 0

    def __iter__(self):
        return self

    def __next__(self):
        if self.current >= self.max_count:
            raise StopIteration
        self.current += 1
        return self.current
```

Understanding iterators is important for building efficient data pipelines.

## 4. Context Managers

Context managers help manage resources such as files, database connections, and network sockets.

Example:

```python
with open("sample.txt", "r") as file:
    content = file.read()
```

Custom context manager:

```python
class DatabaseConnection:
    def __enter__(self):
        print("Connection Opened")
        return self

    def __exit__(self, exc_type, exc_value, traceback):
        print("Connection Closed")
```

Advantages:

* Automatic resource cleanup
* Improved readability
* Better exception handling

## 5. Multithreading

Multithreading allows multiple threads to execute concurrently within a process.

Example:

```python
import threading

def task():
    print("Task Running")

thread = threading.Thread(target=task)
thread.start()
thread.join()
```

Use cases:

* Network requests
* I/O operations
* Background tasks

Python's Global Interpreter Lock (GIL) may limit CPU-bound multithreading performance.

---

## 6. Multiprocessing

Multiprocessing creates separate processes that can run on multiple CPU cores.

Example:

```python
from multiprocessing import Process

def worker():
    print("Worker Process")

p = Process(target=worker)
p.start()
p.join()
```

Advantages:

* True parallel execution
* Better performance for CPU-intensive tasks

Common applications include machine learning, data processing, and image analysis.

---

## 7. Async Programming

Asynchronous programming allows tasks to run without blocking the main thread.

Example:

```python
import asyncio

async def fetch_data():
    await asyncio.sleep(1)
    return "Data Received"

async def main():
    result = await fetch_data()
    print(result)

asyncio.run(main())
```

Key concepts:

* Event loop
* Coroutines
* Awaitable objects
* Non-blocking I/O

## 8. Metaclasses

Metaclasses define how classes themselves are created.

Example:

```python
class Meta(type):
    def __new__(cls, name, bases, attrs):
        print(f"Creating class {name}")
        return super().__new__(cls, name, bases, attrs)

class MyClass(metaclass=Meta):
    pass
```

Metaclasses are commonly used in frameworks such as Django ORM and SQLAlchemy.

## 9. Descriptors

Descriptors customize attribute access using special methods.

Methods:

* **get**()
* **set**()
* **delete**()

Example:

```python
class PositiveNumber:
    def __get__(self, instance, owner):
        return instance._value

    def __set__(self, instance, value):
        if value < 0:
            raise ValueError("Must be positive")
        instance._value = value
```

Descriptors power properties, ORM fields, and validation systems.

## 12. Abstract Base Classes

Abstract Base Classes (ABC) define interfaces that subclasses must implement.

Example:

```python
from abc import ABC, abstractmethod

class Shape(ABC):

    @abstractmethod
    def area(self):
        pass
```

ABCs help enforce consistent design patterns.

## 15. Concurrency vs Parallelism

Concurrency means managing multiple tasks at once.

Parallelism means executing multiple tasks simultaneously.

Comparison:

* AsyncIO → Concurrent I/O operations
* Threading → Concurrent execution
* Multiprocessing → Parallel execution

Choosing the correct model depends on workload characteristics.
